# Lockerly web pages

Publish this `Web` directory to the `firnsilk/lockerly-web` GitHub Pages repository.

Before publishing:

1. Confirm the effective date and legal copy.
2. Provide the final support email and add it to the support page.
3. Configure the same email as `LockerlyFeedbackEmail` in `project.yml`.
4. Keep the published URLs in App Store Connect synchronized with this directory:
   - `https://firnsilk.github.io/lockerly-web/privacy/`
   - `https://firnsilk.github.io/lockerly-web/terms/`
   - `https://firnsilk.github.io/lockerly-web/support/`
